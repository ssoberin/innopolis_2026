Постановка задачи: выделение дополнительных услуг из объявления, создание черновиков, требования и формат входа и ответа решения.

Критерии оценки решений, распределение баллов, расчёт micro-F1 и требования к защите и live-демо.

microcategories-guide.md
Краткий справочник микрокатегорий с описаниями и примерами услуг.

public-test-dataset.parquet
Набор из 208 записей с объявлениями и метками категорий. Поля: title — заголовок, description — описание, categories — список названий категорий.

public-train-annotated.jsonl
10 000 объявлений с автоматической разметкой, подготовленной с помощью модели GPT-6. Разметка выполнена с применением предметных правил и смысловой проверкой выбранных сложных случаев моделью; она может содержать ошибки и не является вручную проверенным эталоном.

Формат JSONL: каждая строка — отдельный JSON-объект:
• item_id — идентификатор исходного объявления;
• title — исходный заголовок;
• description — исходный текст объявления;
• found_microcategories — массив найденных дополнительных микрокатегорий. Каждый объект содержит mcId — идентификатор и label — название микрокатегории.

Исходной для всех объявлений считается 101 «Ремонт под ключ». Она не включается в found_microcategories: возможны только 102–106. Если дополнительных категорий нет, массив пустой.
