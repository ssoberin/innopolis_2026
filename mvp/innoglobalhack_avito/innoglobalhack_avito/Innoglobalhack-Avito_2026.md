# Выделение услуг из других микрокатегорий и создание черновиков объявлений

## Контекст

В Авито Услугах объявления размещаются в определённых микрокатегориях. При этом в одном объявлении исполнитель может описывать несколько услуг, относящихся к разным микрокатегориям. Например, в объявлении о ремонте квартиры под ключ могут быть указаны сантехнические и электромонтажные работы.

Само объявление размещено только в одной микрокатегории. Дополнительные объявления в других релевантных микрокатегориях могут помочь исполнителю представить свои услуги пользователям, которые ищут конкретный вид работ.

Хотим автоматически находить такие услуги в существующем объявлении и предлагать исполнителю дополнительные черновики для проверки, редактирования и последующей публикации.

## Задача

Разработать решение, которое по тексту объявления и его текущей микрокатегории определяет, для каких других микрокатегорий можно создать дополнительные черновики.

В рамках кейса рассматриваются следующие микрокатегории категории «Ремонт и отделка». Для входных данных и ответов решения используются единые идентификаторы кейса:

| mcId | Микрокатегория |
| --- | --- |
| 101 | Ремонт под ключ |
| 102 | Штукатурные работы |
| 103 | Плиточные работы |
| 104 | Сантехника |
| 105 | Электрика |
| 106 | Поклейка обоев и малярные работы |

Дополнительные черновики формируются только для микрокатегорий из этой таблицы.

Решение должно:

1. Выделить услуги, которые исполнитель предлагает в тексте объявления.
2. Определить микрокатегории, к которым относятся эти услуги.
3. Сформировать список дополнительных черновиков для микрокатегорий, отличающихся от исходной.

Если подходящих услуг из других микрокатегорий нет, решение должно вернуть пустой список черновиков.

Нужно учитывать смысл и контекст объявления. Совпадения ключевых слов недостаточно: отрицания, сравнения и упоминания чужих услуг не должны становиться основанием для создания черновика.

## Дополнительная задача — генерация текстов

Для каждого предложенного черновика можно сгенерировать заголовок и текст объявления.

При генерации необходимо соблюдать следующие требования:

- Один черновик соответствует одной целевой микрокатегории. Несколько услуг внутри неё объединяются в один черновик.
- Заголовок и текст должны быть посвящены услугам выбранной микрокатегории.
- Текст должен читаться как самостоятельное объявление: быть понятным без исходного объявления и не ссылаться на него или на выделение услуги из комплексного предложения.
- Можно использовать только сведения из исходного объявления. Нельзя добавлять неуказанные виды работ, цены, гарантии, опыт и другие условия.
- Нельзя утверждать, что услугу можно заказать отдельно, если это не следует из исходного текста.

Черновики не публикуются автоматически: исполнитель должен иметь возможность проверить и отредактировать их.

## Формат взаимодействия

На вход решение принимает:

- `description` — текст исходного объявления;
- `mcId` — идентификатор текущей микрокатегории.

На выходе решение возвращает JSON с полем `drafts` — списком дополнительных черновиков.

Каждый элемент `drafts` содержит:

- `mcId` — идентификатор целевой микрокатегории, отличной от исходной;
- `title` — заголовок черновика;
- `text` — текст черновика.

Определение целевых микрокатегорий — обязательная часть задачи. Генерация заголовка и текста — дополнительная. Если она не реализована, поля `title` и `text` должны содержать `null`.

Для одной целевой микрокатегории создаётся не более одного черновика. Значение `mcId` должно соответствовать таблице микрокатегорий выше; новые микрокатегории не создаются.

## Пример

Вход:

```json
{
  "description": "Делаем ремонт квартир под ключ, а также отдельно выполняем сантехнические работы: разводку труб, установку раковин и унитазов, замену смесителей и подключение стиральных машин. Помогаем подобрать материалы и согласовываем стоимость до начала работ.",
  "mcId": 101
}
```

Ответ с генерацией текста:

```json
{
  "drafts": [
    {
      "mcId": 104,
      "title": "Сантехнические работы",
      "text": "Выполняем сантехнические работы: разводим трубы, устанавливаем раковины и унитазы, меняем смесители и подключаем стиральные машины. Поможем подобрать материалы для работ. Стоимость согласуем до начала работ."
    }
  ]
}
```

Ответ без генерации текста:

```json
{
  "drafts": [
    {
      "mcId": 104,
      "title": null,
      "text": null
    }
  ]
}
```

Если оснований для создания дополнительных черновиков нет:

```json
{
  "drafts": []
}
```

**Примеры объявлений, описания микрокатегорий и ключевых услуг в каждой из них будут предоставлены отдельно.**
